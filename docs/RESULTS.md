# Results

Generated by `scripts/results_table.py` from the run database on 2026-10-17. **Every investigated attempt is included**, failures and infrastructure errors too (an `error` or `blocked` outcome below; causes in "Infrastructure errors"). Runs that failed in setup before any investigation started, including several from while the harness itself was being debugged, stay in the database but are not agent outcomes and are not tabulated.

- Live runs call one of two models on Nebius Token Factory: **Reflection Beam** (`reflection/beam`) and the earlier **Muse Spark Open** (`meta-models/muse-spark-open`). Each report records the exact model it used.
- **Fixture** runs use a scripted test double. They show that the pipeline and the hidden checks work end to end, and say nothing about a model.
- These are six small demo scenarios, one to three runs each. They are **not** a benchmark, and not comparable to SWE-bench or Terminal-Bench. Repeated runs of one scenario are not separate capabilities.
- Some run metrics were **reconstructed from recorded events**, because the headless runner exited before saving them (fixed). Their reports say so.
- Cost is an **estimate** from provider-reported tokens at pinned catalog rates (`config/pricing.json`, read from `GET /v1/models?verbose=true`): Muse Spark Open $1.25 / $4.25 and Beam $0.25 / $1.00 per M input/output tokens, with no cached-token discount applied.

## Beam on local kind, 2026-10-17

Five scenarios investigated live with Beam after the `reasoning_content` fix (`5174efb`), each on its first attempt:

| Scenario | Outcome | Tool calls | Policy rejections | Tokens |
|---|---|---|---|---|
| selector-mismatch | resolved | 48 | 0 | 502,319 |
| broken-readiness | resolved | 43 | 0 | 443,612 |
| invalid-config | resolved | 47 | 0 | 543,817 |
| memory-pressure | resolved | 41 | 0 | 408,285 |
| partner-outage | **escalated** (correct: the cause is in another namespace) | 41 | 0 | 293,231 |

In `partner-outage` Beam called no mutating tool at all. It read logs, events, endpoints and reproduced the 502 through the Service, then escalated naming the gateway and its namespace. Applying a change there would have been the wrong answer, and the hidden checks reject a claimed recovery.

The earlier Beam `application-bug` run on kind predates these changes and has not been repeated on the current code; `application-bug` needs a fresh image build, which the current network cannot reach.

**Beam returns no visible decision text.** Its prose arrives in the provider's `reasoning_content` field, which this project never stores or displays, so Beam timelines show tool calls, results and `note` entries but no per-step decision notes. Muse Spark Open populated those. This is a presentation difference, not a capability one.

## Infrastructure errors

| Run | Scenario | Where | Cause |
|---|---|---|---|
| `20261017-154852-3f7dd6` and four more | all five kind scenarios (live, Beam) | during investigation; counted as `blocked` | Beam rejects a multi-turn tool-calling request whose earlier assistant turns carry no `reasoning_content`, so each run failed on its second model call. The flag the error suggests, `allow_missing_thinking`, was verified to be rejected by the endpoint; echoing the field back is the only accepted form. Fixed in `5174efb`: the field is replayed into the request only, and never stored, logged or displayed. |
| `20261017-171907-946071` | selector-mismatch (live, kind, Beam) | tabulated as `unresolved` | Beam repaired the selector correctly and confirmed recovery, then spent its remaining steps re-auditing unrelated pricing code and never called `finish`, so the repair was discarded and hidden verification never ran. Fixed in `5174efb`: with five steps left the loop states how much budget remains, without hinting at what the repair should be. |
| `20261016-162115-3ce661` | selector-mismatch (live, Civo, Muse) | during investigation; counted as `error` | A Kubernetes API call hung for 71 min with no client timeout, then failed (`NewConnectionError`). Fixed: request timeouts, per-tool time limits, and network errors returned to the agent as tool errors. |
| `20261016-155915-d5beab` | selector-mismatch (fixture, Civo) | setup, not tabulated | `docker push` to ttl.sh timed out after 600 s. Fixed: one retry with a longer timeout. |
